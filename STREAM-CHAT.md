# Stream Chat — асинхронный диалог во время стрима

> Канал общения между пользователем и агентом без прерывания стрима.
>
> **Правила:**
> - Агент пишет вопросы / наблюдения / уточнения сюда вместо вопросов в чате.
> - Пользователь иногда заглядывает и пишет ответы прямо в этот файл.
> - Агент периодически перечитывает файл и реагирует на ответы.
> - Это **не** замена `CYCLE-LOG.md` (там лог хода работ) и не `TODO-cycle.md` (там отложенное на будущее).
>
> Создан: Стрим 1, по инициативе пользователя.

### Workflow на оставшиеся стримы

```
Стрим N start
  → ход работ
  → коммиты
  → финал стрима

  → если есть новое сообщение → реакция и ответ здесь
  → Стрим N+1 start
```
