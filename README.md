# SkyGraph

Реактивная UI-библиотека: `@skygraph/core` (runtime + engines) и `@skygraph/react` (хуки + компоненты).

Документация для разработчиков: [docs/README.md](./docs/README.md)

---

Отдельный Git-репозиторий. Родительский репозиторий Skycode при необходимости можно настроить так, чтобы не дублировать историю (например, добавить `skygraph/` в `.gitignore` родителя или использовать submodule).
