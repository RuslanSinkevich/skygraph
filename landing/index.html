Multi-framework reactive UI library

Multi-framework UI-библиотека

A shared headless engine and identical components for React and Vue. Forms, tables, trees, diagrams, charts and dashboards on one reactive core. Pixel-identical rendering across adapters, zero-runtime CSS, MIT licensed.

Общее headless-ядро и идентичные компоненты для React и Vue. Формы, таблицы, деревья, диаграммы, графики и дашборды на одном реактивном движке. Pixel-identical рендер, zero-runtime CSS, MIT.

function App() {
  return (
    <Form defaultValues={{ email: '' }}>
      <Field name="email" label="Email" />
      <SubmitButton>Submit</SubmitButton>
    </Form>
  )
}

Why SkyGraph
Особенности

Designed around a reactive engine, not a render layer

Построено вокруг реактивного движка, а не render-слоя

Headless core

Headless-ядро

Path-based store with granular subscriptions, transactions, batching, middleware and time-travel debugging. Six engines on top: form, table, tree, virtual, graph, calendar.

Path-based store с точечными подписками, транзакциями, батчингом, middleware и time-travel. Поверх — 6 движков: form, table, tree, virtual, graph, calendar.

Zero-runtime CSS

Zero-runtime CSS

91 design tokens, light/dark themes via data-sg-theme, transitions and print layer. ~25 KB gzip, no CSS-in-JS overhead.

91 design-токен, light/dark через data-sg-theme, transitions и print-слой. ~25 KB gzip, никаких CSS-in-JS.

Pixel-identical adapters

Pixel-identical адаптеры

React and Vue emit the same .sg-* classes and DOM shape. A parity test suite of 30+ component snapshots keeps both in sync on every PR.

React и Vue эмитят одинаковые .sg-* классы и DOM. Тесты паритета на 30+ снапшотов держат адаптеры в синхроне на каждом PR.

Type-safe

Type-safe

TypedCore wrapper for compile-time path validation. Schema forms from JSON Schema or Zod. Full TypeScript strict, no any at the API surface.

TypedCore-обёртка для проверки путей на этапе компиляции. Schema-формы из JSON Schema или Zod. TS strict, без any в публичном API.

Accessible by default

Доступность из коробки

ARIA roles and attributes on all components, keyboard navigation, focus traps, roving tabindex, axe-core smoke tests in CI.

ARIA-роли и атрибуты во всех компонентах, клавиатурная навигация, focus-trap, roving tabindex, axe-core smoke-тесты в CI.

Print & PDF

Print и PDF

printable prop and ref.print() on Table, Diagram and all charts — native browser print dialog, no runtime dependencies.

Проп printable и ref.print() на Table, Diagram и всех Charts — нативный print-диалог браузера, без runtime-зависимостей.
